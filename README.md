Este é o repositório oficial da api do projeto TimeBank.

***INSTRUÇÕES PARA RODAR O PROJETO***

Clone o repositório em sua máquina local e rode os seguintes comandos:

`npm i`
`npm run dev`

Acesse a API via http://localhost:3000

Acesse a documentação via http://localhost:3000/api-docs/

Neste endpoint estará o primeiro fluxo de dados relevante para o projeto.
